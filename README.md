# Padworks: O&G Completions Simulator

Interactive 3D equipment library and stage-cycle simulator for oil and gas well completions. Built for training. Not for operational decisions. Written, modeled, and coded independently from public sources.

Live at https://padworks.vercel.app (GitHub repository joshlambert13-bot/padworks). The local folder may still be named completions-explorer; the folder name has no effect on the build.

Drop 41: instancing. The pad's repeated units no longer cost a draw call per mesh per unit. `Instanced` renders a unit once as a hidden template, bakes the template's meshes into one geometry per material and record name, and draws every unit as one InstancedMesh with a matrix per unit: 13 pump bodies, 8 frac tanks (as four cream-and-white pairs), the fuel gas trailers, the parked pickups, the 24 sand boxes, and the 10 light towers. Hover and click still open the right record because each instanced mesh carries the group's name. The parts that move, light up, or differ per unit (pump fans, status lamps, exhaust plumes, pump numbers) are drawn per unit on top. Pixels are identical; the draw-call count at the pad overview drops by about half, which is what a laptop GPU or a phone feels.

Drop 42: shareable job links. A Share button on the Simulator toolbar copies a link that opens the job as it is now: basin and setup, pad, phase, stage, time of day, season, and camera preset, packed into one URL-safe token. Opening the link rebuilds the job from the setup and plays the phase and stage forward, so a trainee lands in the scenario rather than at the setup screen. The token holds no account data and no score; progress stays with the account that opens it.

Drop 43: field report fixes. A Stats button on the Simulator toolbar shows frame rate, frame time, draw calls, triangles, Lite or Full and whether the effects are on, the viewport size and pixel ratio, the graphics chip, and any shader compile error, so a screenshot of that line says what a machine is doing. The instanced units (frac pumps, frac tanks, boxes, fuel trailers, pickups, light towers) now bake with standard materials instead of physical ones, which removes the heaviest shader from the instanced path; a frac tank body that went dark on one laptop is the suspected case, and the Stats line will confirm or clear it. Each frac pump's suction hose now runs from the missile's low-pressure outlet beside it to the pump's manifold end, one per pump, instead of a loose hose baked into every pump copy. The sand box station's cradles moved to the west end of the collecting belt and the box stack moved 30 m further west, so the container handler's run stays clear of the pump row. The frac tank stairs land on the walkway: ten treads at the rise and run of the tank's height. Sign text is fitted line by line to the sign face. The seal flags (North Dakota, Louisiana, Pennsylvania, Oklahoma, Wyoming) are real artwork from `public/flags/` (a permissively licensed npm package's traced SVGs, see the README there) drawn over the coded flag, and every flag now reads correctly from both sides, as a printed two-ply flag does, rather than mirrored from the back.

Drop 44: ground and weathering. The pad reads as a used pad instead of a painted rectangle. A stain map drawn over the pad's rectangle from the real layout (`padStainTexture`, src/sim/parts/ground.js): the truck lanes with their ruts (the entrance from the lease road, the east service loop past the wireline and flowback side, the lane behind each pump row that the pump trucks back in from, the sand and water lane), compaction under the pickups and fuel trailers, oil under each pump's power end with drips, the wet slurry zone around the blender and hydration unit, drips at the chemical add and fuel row, the cellar ring at each wellhead, the wet ground at the flowback tanks and water manifolds, spilled sand at the silos or boxes. The pad material multiplies it in world space, so it never repeats and it moves with the layout (basin, pump count, sand mode, water source). The gravel tile lost its baked ruts, which repeated every 16 m. Every unit weathers by one shader patch (no new draw calls, no new textures): a dust and grime band over the lowest 1.6 m above the pad, gated by world-space noise stretched into vertical streaks, so tires, chassis, skids, and tank bottoms carry dirt and the tops stay clean; bare steel (`steel`, `darkSteel`, `dimSteel`, `chassis`, `grating`) takes fine rust speckle from a second world-space noise. The downhole section and the library viewer stay clean. Optional photo textures: files dropped into public/textures (CC0 sets from Poly Haven; the README there lists the exact names) are blended into the drawn ground, paint, and steel tiles at load, reduced to luminance so the basin and paint colors stay what they are; nothing changes when the files are absent.

Drop 45: light and color. The sky is three's Preetham atmosphere (an analytic daylight model: Rayleigh and Mie scattering from the sun's position, turbidity, and haze) instead of a painted gradient, so the horizon haze, the brightening toward the sun, the zenith blue, and the dusk colors all come from one physical model; in Full the model's own cloud layer carries the cloud cover (by basin, overcast in winter), Lite keeps the sprite clouds over the clear-sky shader. Night keeps the moon and the star field over a faint moonlit sky. The reflections see the same atmosphere. Tone mapping moved from ACES to AgX (a flatter, more photographic curve with gentle highlight roll-off; the sun presets' exposures are scaled to match) and in Full a grade pass adds a touch of contrast and saturation back and a soft vignette; these merge into the bloom's pass, so they cost no render target. Ambient occlusion is stronger and reaches further (radius 1.7 m, intensity 3), so contact shadows under skids, tires, and pipe stands read. The Stats readout now counts the whole frame when the effects are on (it used to show the last pass's single quad).

Drop 46: silhouette pass, first round. Every trailer on the pad (pumps, blender, hydration, chemical add, data van, fuel trailers, wireline and coil units, power generation) has quarter fenders over each tire, which is the one shape a loaded trailer always shows from the side and these did not. The frac tanks got shell plate seams, two bolted roof manways with hatch handles, a sight glass with its scale on the front bulkhead, a no-smoking placard by the valves, the capacity stencil on both sides, and a painted tank number on each tank (worn stencil lettering drawn on a transparent decal, alpha-tested so it costs no sorting; the numbers sit outside the instanced template so each tank is its own). The pump fluid ends have bolt circles on every valve cover and discharge flange. Sun shadows use PCF with a 3-texel radius in Full (the soft shadow type was removed from three in 0.186 and had silently fallen back to hard edges).

Drop 47: crew figures and photographic skies. The crew are no longer mannequins: capsule limbs with knees and elbows, a lathed torso with shoulders, boots, gloves, safety glasses, a hard hat with a peak, FRC coveralls in navy, tan, or charcoal by crew member, the high-visibility vest with its reflective bands, and bands on the forearms and shins. Poses are built from joint positions (stand, point, kneel with the right knee down and the torso leaning into the work), and the walking figure's legs and arms swing from the same parts. The photographic skies are wired: when `public/textures/sky_day.hdr`, `sky_dusk.hdr`, or `sky_night.hdr` is present (CC0 HDRIs from Poly Haven, see the README there), the Full renderer uses it as the visible sky and as the environment for reflections for that time of day in summer, turned about the vertical so the photograph's sun sits at the azimuth of the pad's sun light, which keeps the visible sun and the shadows on the same side. The brightest pixel of the map is taken as its sun. Winter, Lite, and any time of day without a file keep the atmosphere model.

Drop 48: pad life. The small things a working pad is never without, all generic and merged or instanced: six IBC totes on pallets with their cages and valves at the chemical add, a rack of spare treating iron with hammer unions and two swivels on timbers by the missile, traffic cones along both red zone edges, water-filled barricades at both pump row ends, a dumpster and two portable toilets by the parking, a diesel fuel cube by the pump row, spill kit drums with an extinguisher stand at the chemical add and the fuel row, and coiled lay-flat hose on pallets by the water transfer. After dark each light tower's lamp head carries a soft glow (an additive sprite), so Lite shows the haze around the heads that bloom gives in Full.

Drop 49: ground and horizon shading. The plain around the pad is no longer one tone: the ground materials take patches of darker soil and lighter caliche at 30 m and 4 m scales from world-space noise in the same material patch that does snow and grime, so the variation never tiles and costs no texture. The horizon rock gets strata bands by height (wavering with position so the bands are not rulers) and its cliff faces shade darker and redder than the caps and talus by slope, which is how a mesa or a ridge reads from a distance.

Drop 50: the flowback tanks, properly. The report of hanging bars and stairs on the flowback tanks was right and the Drop 43 fix went to the water tanks instead: the three tanks behind the flowback spread were an older model with a full half-round roof, a rail along the crown ridge with no walkway under it, and a stair up the end that stopped in the air. They are now the same 500 bbl tank as the water side (one shared `FracTankBody`), in dark paint with light stencils, numbered FB-1 to FB-3, with the walkway, rails, stairs, manifold, seams, manways, and sight glass that come with it; the three are instanced, so the change also removed draw calls.

Drop 51: Lesson 9, gun misfire. The ninth guided lesson starts with the pump-down string almost at depth and a misfire armed: the plug sets, the guns fire a cluster short, and the lesson walks the recovery in order: read the short fire count against the design, let the string come back to the lubricator, re-arm and run again on the pump, fire the missed cluster once the guns are armed at depth, pull out. Time target four minutes; the event's time-to-recover clock scores it like the instructor-injected misfire. The headless pass plays the lesson through (fire, misfire, re-run, fire, complete).

Drop 52: blender, hydration, and chemical add detail; flags from behind. The blender has its tub rim and inspection hatch, hopper grates, auger drive motors with their hydraulic hoses, discharge piping from the tub to the pump, butterfly valves with red handles on both manifolds, chemical injection pumps, an exhaust stack, cabin roof lights and a console, a rear stair to the deck, and a hazard stripe at the hopper. The hydration unit has mixer drive motors with hoses back to the power pack, butterfly valves on its suction manifold, the gel pump with its suction hose, an exhaust stack, shell seams, a rear stair, and a HYDRATION stencil. The chemical add unit has cages on its totes, feed lines from the totes to the cabin, a metering pump cabinet, a containment lip on the tray, and a stencil. The flags: a report that they hung the wrong way from behind was right. The two-ply reverse from Drop 43 mirrored the whole design, which put the US canton and the Texas hoist stripe at the fly end when seen from behind. Now only the lettered seal flags (Oklahoma, North Dakota, Louisiana, Pennsylvania, Wyoming) carry the mirrored reverse ply, so their words read correctly from both sides with the seal centered; the others are one cloth, and the canton stays at the pole from either side as on the real flag. The Stats line shows the render pixel ratio (Full caps it at 1.5) beside the screen's.

Drop 53: night, second pass. Each frac pump carries a work light over its control panel after dark, with a glow; the blender's cabin glass is lit; and when the flare is burning at night it throws orange light across the flowback spread (one point light, shadowless) under a wide glow. With the tower lamp glows from Drop 48, a night pad now reads as a lit workplace in Lite as well as Full.

Drop 54: zipper legs instanced. The static iron of every zipper leg (base, tee, risers, flanges, bolt rings, elbow and outlet, transducer, junction box, gauge, hydraulic hoses) is one instanced set over the legs, one draw per material instead of twenty-odd meshes per leg; the two valves per leg, whose open and closed states differ well by well, stay per leg. Hover names ride on the instanced set, so any leg picks as the zipper leg.

Drop 55: rust, less of it. The field report that the pumps read as rusty was fair: the world-space rust speckle from Drop 44 was on every bare-steel material at the same strength, including the painted castings (power ends, transmissions, manifolds) that are dark steel in the model. Rust now sits mostly on chassis, grating, and dim steel, lightly on bare steel, and barely on the dark castings.

Drop 56: walk the pad. A Walk button on the Simulator toolbar puts the camera at eye height, 8 m short of whatever the orbit camera was looking at and facing it. W A S D or the arrow keys move, Shift runs, dragging the view (mouse or one finger) looks around, Escape or the Walk button returns to the camera preset; phones get on-screen arrows in the walk bar. The walker follows the ground outside the pad and stays within 60 m of the pad edge. Hovering and clicking equipment keep working at eye level, which is the point: a trainee can stand at the zipper and read the valves, or walk the pump row and look under the trailers. The headless pass enters and leaves walk mode and checks the camera height both ways.

Drop 57: frac trees instanced. The four (or six) frac trees were the biggest remaining draw-call item: each one was about 110 meshes, every well its own copy. The tree is now drawn in two layers. Everything that is the same on every well (the wellhead in its cellar, the adapter, the valve bodies with their flanges, studs and fittings, the cross, the inlet block, the hydraulic hoses, junction box and gauge) is rendered once and instanced over the wells that carry a frac tree, and the well color rides on the instance color, so the trees still read green, blue, white, red, with the partner wells dimmed as before. Each well then draws only what moves or differs: the stems, handwheels, actuator plates and position lamps as a few merged meshes, the labels and pulse ring on your well, the well number and danger signs, and the lubricator or ball launcher on top; the bare top adapter is a second small instanced set. Hovering any well's valves now opens the records (the partner wells used to be mute). The instancing baker also learned to expand instanced parts inside a template, which brings back the zipper leg studs that Drop 54 had silently dropped. Lite overview: 2,097 draw calls to 1,547.

Drop 58: production trees and zipper valves instanced. The same split as Drop 57, applied to the two places still drawing a copy per well: the production tree (wellhead, adapter, masters, flow cross, wing valve, choke, flowline drop and kill wing are one instanced set over the wells on production, tinted per well; the swab valve, cap or stuffing box or plunger lubricator, and the lift equipment stay per well) and the zipper legs, where the two valve bodies with their flanges and fittings now bake into the Drop 54 leg set and only the stems, actuator rings and lamps are drawn per leg, as a few merged meshes. Partner production trees pick as the tree records now too. Lite overview: 1,547 draw calls to 1,482; the production phase on a four-well pad drops by about 150 more.

Drop 59: walk on a phone. Narrow screens get a thumb-sized walk pad in the lower right corner of the 3D view (forward, back, left, right, and a Run toggle in the middle) instead of the small arrows in the toolbar; the toolbar hint reads for touch (drag to look, arrows walk, the Walk button leaves). Desktop keeps the keyboard hint and the small arrows. Checked on a 390 by 844 viewport: the pad sits above the tagline, a held arrow moves the camera, and the Walk button ends the walk.

Drop 60: sound with a position. While walking the pad, the working sounds come from where they are: the pump fleet is loud at the missile and falls off with distance, the choke hiss belongs to the flowback spread, the wireline whine to the wireline unit, the injector and mill noise to the coil unit and the well, and each one pans toward the side it is on as you turn. Stand between the pump rows and the rumble fills both ears; walk to the flowback tanks and it drops behind the choke. Leaving the walk returns the plain pad mix. The wind bed and the alarms are not positional. Found and fixed on the way: the walk listeners were being re-installed on every sim tick, which let a held on-screen arrow drop out while the job was running.

Drop 61: walk with a body. The walker no longer passes through the units. When a walk starts, every visible mesh in the scene (each instance of an instanced set on its own) whose footprint stands at body height and is at least half a meter across both ways becomes an obstacle; pipes, hoses, masts, flags, cones and the berm are thin enough to walk past, and whole-area bakes (the ground, the pad, the flowback spread's one-piece skids) are left out. The walker is pushed out of anything it steps into along the shorter way, so it slides along a trailer instead of stopping dead, and a walk never starts inside a unit. Checked by walking into the data van (stops 0.6 m off its wall, strafes free) and between two pumps (slides down the gap). Also: the trailer frames' rust pulled back a notch, they read as camouflage at the Drop 44 level.

Drop 62: full screen. A Full screen button on the Simulator toolbar folds the control panel, the timeline, the mobile tab bar and the site header away so the 3D view takes the whole window, and asks the browser for real full screen where it allows it (desktop browsers do; most phones only fold the panels). The toolbar stays, so camera presets, Walk, Labels, Day and the rest keep working; the same button (now Exit) or Esc brings everything back, and leaving the Simulator page always does. The headless pass toggles it both ways and checks the canvas width.

Drop 63: panels on call in full screen. Two slim tabs sit on the left and right edges of the full screen view; the left one slides the control panel over the 3D view (valves, lessons, events, all live), the right one the timeline, and the same tab tucks it away again. The toolbar shifts clear of an open panel. So a trainee can run a whole stage in full screen: fold the panel out to open a valve, fold it back to watch the pad.

Drop 64: photo, and a quiet full screen. A Photo button on the toolbar saves the 3D view as a PNG at the render size, with the effects in it when they are on and without any panels or toolbar, named by camera preset, phase and time (padworks-pumps-frac-20261004-1150.png), ready for a slide or a problem report. In full screen the toolbar and the edge tabs fade out after three quiet seconds and come back on any mouse move, key or touch, so a presentation shows the pad and nothing else. The headless pass takes a photo and checks the file.

Drop 65: tour. A Tour button on the toolbar sends the camera around the pad on its own: a slow drift around each view, then an eased move to the next, pad to tree to well row to zipper to pumps to sand to tanks to data van to gate to flowback to the basin and around again, with the preset dropdown following. Any click, drag or scroll on the view stops it where it is, as does picking a preset, Walk, or the button itself. With Full screen and the fading toolbar it is a demo loop for a lobby screen or the start of a class.

Drop 66: two tour stops reframed. Running the tour showed the frac tree view from the north-east had the wireline crane's boom across it whenever a lubricator was up, and the flowback view sat on top of the tanks with the spread small behind them. The tree view now looks from the south-east (your tree in front, the spool from the zipper coming in, the next well and its lubricator behind, the pumps beyond), and the flowback view looks down the spread from the wells, choke manifold to plug catcher to separators with the tanks behind and the flare at the edge. The water preset is named Water supply, since by basin it may be frac tanks, a lined pit or an above-ground tank.

Drop 67: the sim steps at 20 Hz. The simulation used to advance once per rendered frame, and every store update re-renders the panels and the whole scene tree, so at 60 frames a second the browser was doing three times the React work the simulation needed. The tick now accumulates frames and runs every 50 ms; the sim rate is unchanged (a step was already capped at 100 ms, and slow machines tick every frame as before), valves, gauges and the chart move at 20 Hz, and the frame has that time back. The point is phones, where the main thread is the limit.

Drop 68: weather. A Weather button on the toolbar cycles clear, overcast and rain, on top of the season and time of day. Overcast is a closed gray deck with soft white light and no sun disk; rain is darker still, the haze close, streaks falling with the wind, and the pad wet: up-facing surfaces darken and go glossy, the ruts and spills in the stain map become puddles, and the sound gets a rain bed. The photographic sky stands down under a cloud deck. The headless pass cycles the weather at the flowback and checks the rain voice.

Drop 69: lightning. While it rains, a strike every 20 to 60 seconds: two or three flickers of blue-white light over the pad from a random bearing with the sky lit behind it, then thunder one to five seconds later, a low roll that is softer the longer the delay (sound on). Nothing runs between strikes but a timer. At night it is the best-looking thing on the pad.

Drop 70: lightning hold. The weather is now something the instructor can do to a trainee. A new event, Lightning within 10 miles, brings the storm with it and puts the pad on a weather hold: the guidance says pumps offline and rate to zero, crews off the pad, hold for the all clear (60 s of sim time here; a real hold is 30 minutes after the last strike). Time to shut down is scored like the other events (target 30 s), restarting the pumps before the all clear costs 10 points, and the all clear lifts the storm to overcast. Lesson 10, Lightning hold, drops it into a pumping stage: stop, hold, bring the rate back, sand back in. The headless pass runs the lesson.

Drop 71: the headless pass in three runs. The sandbox that runs the pass restarts itself about every seventy minutes, and the pass had grown past that, so it now runs as three parts (ONLY=main, the walkthrough and library; ONLY=drop7, the pad setup, basins, records and lessons; ONLY=tail, accounts and phone) of 35, 35 and 10 minutes, each with its own screenshot folder and error count. Same 180 shots, same checks.

Drop 72: lightning in the library. A Lightning hazard class (what the tall steel on a pad does in a storm, and the ten-mile-ring control), a glossary entry for the lightning hold with its aliases, and the hazard on the light tower record, so the weather hold the Simulator teaches has its reading side in the library and the Build check.

Drop 73: the pad clutter answers the pointer. Fifteen things on the pad had no record and said nothing when hovered: the chemical totes, the welfare trailer, the fuel cube, the iron rack, the hose coils, the safety station and muster point, the cones, the barricades, the crew pickups, the flags and wind sock, the frac water heater, the lined pit, the water transfer, the sand box station, and the crew themselves. Each now has a logistics record (what it is, how it is sized, the safety side, the hazard class where one applies), so a click on anything on the pad opens something. 337 records; the Build check passes. The pass hovers the fuel cube.

Drop 74: treating iron leak. A new event, Treating iron leak, and Lesson 11 around it. Mid-stage, a hammer union on the high-pressure line from the missile lets go at the seal: a spray fans out of the joint and a wet patch spreads under it, a hiss comes from the union when you walk near it, and the guidance turns into the sequence the pad runs: rate to zero and pumps offline, isolate the line at the zipper working valve, bleed it to zero (the spray dies as the line comes down), clear the red zone and swap the joint, pressure test the new iron against the closed valve, then open up and bring the stage back. Two mistakes cost points and are the lesson's reason for being: pressing Swap the iron while the line still holds pressure (15 points; the swap does not happen), and bringing the pumps online on the new joint with no test (8 points). The event is in the random pool while pumping. The treating line itself now answers the pointer with the flow iron record, and the glossary gains Red zone, Pressure test and Bleed-off. The pass runs the lesson start to finish and makes both mistakes on purpose.

Drop 75: field report fixes. You could walk through the pit berm and stand in the water, because the walk obstacles skip anything over 30 m long (the ground and the pad berm have to fall through) and the pit berm is one 50 m piece; the same hole let you walk through the flowback spread's baked units and the big storage tanks. The instancing baker now writes every source mesh's own box onto the set it bakes, so each baked unit is an obstacle again; the pit writes one keep-out box over the whole pit, berm included; the area limit went from 150 to 400 square meters so a 16 m storage tank counts. Hovering now reads only the nearest thing under the pointer: standing inside the berm used to show the record of whatever was behind it (the data van, from the pit). Rain, flurries, stars, the leak spray and the labels no longer catch the pointer ray at all. The pump-row spotter's pointing arm, straight out at shoulder height, read as a salute; it is now a bent arm aimed low and ahead, the way a spotter walks a truck in.

Drop 76: photographic materials, the wiring. Every material now names a family (paint, steel, rust, rubber, ground, terrain, sand, concrete, plastic, liner, fabric, hivis) and each family owns one slot for a CC0 texture set in public/textures: color, normal, roughness and ambient occlusion, sampled in world space on every surface of that family (triplanar, so nothing needs UVs and a photograph lands on a cylinder as cleanly as on a box, at one real-world scale per family). The color map is normalized to its own mean, so the palette still says what color a thing is and the photo adds the structure; the ground and sand let the photo's own hue through. The normal map perturbs the shading with per-axis sign handling so the bumps light the same way on every face. Decals come in the same way: oil PNGs under every power end and at the drips, stains on the wet spots, tire tracks along the truck lanes, cracks scattered on the pad, one draw call per kind. Until the files are in the folder nothing changes; the folder's README lists every name. Full quality only; Lite loads none of it.

Drop 77: a landing page, Lessons mode, and narrated demos. The site no longer drops you into the simulator: the front page offers Lessons, the Full simulator and the Library, and a Watch the introduction button. Lessons is a page of its own: the introduction (a narrated tour of the pad, about four minutes) and the eleven lessons, each with Watch and Try it. Watch is a demo without a video file: the simulator performs the lesson itself, step by step, with a caption bar at the bottom of the 3D view and the browser's own voice reading each step (a neutral American male voice where the machine has one; mute keeps the captions), the camera going where your own click would send it, the rate brought up in steps and the sand added the way a hand would do it. Stop takes over at any point; a demo's result is never saved as your progress. Try it opens the simulator with the lesson started. The demos always match the current build, which a recorded video would not.

Drop 78: the crew are people. Four Mixamo characters (Adobe's free library; the license allows their use inside a project like this) replace the capsule figures in Full quality: standing, pointing, kneeling and walking with real animation, 50,000 triangles each, hair, faces, gloves and boots. They come from Mixamo in street clothes; a repaint in the build pipeline (scripts/crew-frc.py) reads the skeleton to know which part of the texture atlas is torso, arm, leg, hand, foot or head and paints FRC coveralls in the crew color over the clothes with the original folds kept as shading, a hi-vis vest zone with reflective bands at chest and waist, bands on the arms and shins, leather gloves and work boots; the head stays the character's own. The hard hat is drawn by the site and rides the head bone. Blender runs in the build (the bpy module), so the FBX files from Mixamo go in one end and 3 MB GLBs come out the other: scripts/mixamo-to-glb.py converts, crew-frc.py paints, crew-pack.mjs fixes the materials, quantizes and packs. Lite keeps the capsule figures, and while a model loads the capsule stands in its place.

Drop 79: downloaded props and a credits page. Sixteen of the models you pulled are on the pad: barrels by the totes, pallets and tires at the iron rack with a forklift and a shipping container behind, extinguishers at the safety points, jerrycans at the fuel cube, a toolbox, boxes, trash cans, two porta potties, a dumpster and a water tank at the welfare trailer, cones at the pump lane. The pipeline (scripts/props-pack.mjs) brings each one to its real size standing on the ground, caps the textures, converts Sketchfab's older material format, simplifies anything over 20,000 triangles, and writes a credits entry; repeated props go through the instancing baker so all the barrels are one draw. The About page gained a Credits section listing every CC-BY model with its author, source and license, which is the attribution the license asks for, plus the CC0 and Mixamo notes. The Propell pump stays out (a manufacturer's model of its own product); the other vehicles are the next drop.

Drop 80: the vehicles. An iron hauler (semi tractor and flatbed) on the lease road at the gate, a fuel tanker behind the fuel row, a generator trailer by the data van, a second office trailer by the pickups, two more pickups at the end of the row (their badge and plate textures blanked), a telehandler on the sand side. Drop 81: themes, the pad in a customer's colors. A theme names the three companies on a pad and their colors: the pressure pumping company (pump bodies, blender, missile accents and power units in its primary; cabs, trailers, the data van and the fuel row in its secondary), the wellhead company (tree valve bodies and the zipper, with an accent for the actuators), and the operator (pickups, hard hats, vests). The site name, tagline, accent color and logo come along. Three neutral sample themes (red, blue and white fleets) sit next to the default for pitches; the Accounts page gained a Theme panel to pick one, export the current theme as JSON, load a customer's JSON (same shape, their colors and their logo as a data URL), and copy a pitch link that opens the site in that theme (?theme=red-fleet). A change repaints the pad in a few seconds. Themes live in the browser for now; the per-organization version on the accounts server comes with the first customer.

Drop 82: organizations, a customer's theme on the accounts server, and logo plates. The Accounts page gained an Organizations card: a customer (name and slug), the accounts that belong to it (an Organization column in the accounts table), and its theme. The theme is stored from whatever theme is current in the admin's browser (pick a sample or load the customer's JSON in the Theme card, then "Use current theme" on the customer's row), can be previewed back into the browser, and cleared. Each sign-in and page load sends the account's organization theme along, so a customer's trainees and instructors see their colors, site name, tagline and logo on any machine; the theme is cached in the browser so a reload paints it before the pad builds (no repaint), and signing out drops it. Drop 89: the stage from the chair, and the leak that was taking the phones down. The leak first. `Hose` in primitives.jsx memoized its tube on its `from` and `to` arrays, which the scene builds fresh on every render, and the scene renders on every sim tick: every hose on the pad (about ninety) got a new tube geometry twenty times a second while the job ran, and the old ones were never freed. Drop 33: fracture height growth. ## Run it

Requires Node.js 22 (LTS). Inside this folder:

```
npm install
npm run build
npm run serve
```

Open http://localhost:4173. `npm run serve` serves the build and the accounts API with Postgres in process (PGlite, memory only: accounts vanish when it stops). The local admin is `admin` / `padworks-admin`; the first sign-in asks for a new password. For live editing run `npm run api` in one terminal and `npm run dev` in another (the dev server proxies `/api` to the API on port 4174).

On a phone on the same Wi-Fi: run `npm run serve` and open http://<your computer's address>:4173.

## Accounts

Production needs three things in the Vercel project, once:

1. A database: Vercel dashboard, the project, Storage tab, Create Database, Neon (free). Connecting it to the project adds `DATABASE_URL` automatically. The tables are created on the first request.
2. `PADWORKS_SESSION_SECRET`: Settings, Environment Variables, any phrase of 16 characters or more. Signs the session cookies; changing it signs everyone out.
3. `PADWORKS_ADMIN_USER` and `PADWORKS_ADMIN_PASSWORD`: the first admin account, created when the database has no users. The password is one-time: the first sign-in asks for a new one. After that these two variables can stay or go.

Then Redeploy. Sign in, open Accounts, create accounts, hand out the one-time passwords. What is stored: username, display name, role, password hash, lesson results, job summaries, error reports (record ID, page, message, who sent it), sign-in failure timestamps (for the rate limit). No email, no cookies beyond the session, no analytics.

## Review workflow

Every AI-drafted record is `status: "draft"` and is labeled "Unreviewed draft" on the site. To review a record: open the JSON, read every tab, check each citation against the source register, correct the text, then set `status` to `screened` (read once) or `reviewed` (every tab and source checked) and add yourself to `reviewers`:

```json
"status": "reviewed",
"reviewers": [{ "name": "J. Lambert", "affiliation": "Independent", "date": "2026-10-01", "scope": "all tabs" }]
```

`verified` requires two independent sources per numeric value. `npm run validate` refuses a non-draft record with no reviewer.

## Geometry

Two paths, both free:

1. Procedural (Three.js in code): everything in the simulator scenes (`src/sim/parts/`). Node names equal record IDs; a record with `"scene": "WH-FRACTREE"` binds to that node.
2. Scripted CAD (CadQuery): the scripts in `cad/scripts/WH/` build named solids and write uncompressed GLBs into `cad/out/WH/`; `npm run glb` compresses them into `public/glb/WH/`. The shared builders live in `cad/scripts/WH/_lib.py`. You do not need Python on your machine to use the site: the compressed GLBs are already in `public/glb/`. To regenerate, install Python 3.12, run `pip install cadquery trimesh` in a virtual environment, then `python cad/scripts/WH/WH-FRACTREE.py --out cad/out/WH` (and the other scripts: `WH-ZIPPER.py --all`, `PP/PP-MISSILE.py`, `DT/DT-FRACSLEEVE.py`, and the rest), then `npm run glb`. The viewer decodes Draco with the files in `public/draco/`.

## Deploy

Vercel (recommended, free Hobby plan): sign in with GitHub, import the repository, accept the detected Vite settings, deploy, then do the one-time setup under "Accounts" above. `vercel.json` rewrites every path except `/api/*` to `index.html` so record links work; `api/index.js` becomes the one serverless function. Every push to `main` redeploys. Cloudflare Pages and GitHub Pages also work (build `npm run build`, output `dist`; the `404.html` copy handles path routing on GitHub Pages). The step-by-step guide is in the Setup Guide document delivered with Drop 2.

`GITHUB_REPO` in `src/config.js` points the "Report an error" link on each record at the repository's issues page. The logo lives in `public/brand/` (`mark.svg` plus PNG renders).
